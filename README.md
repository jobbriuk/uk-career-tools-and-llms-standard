## 🗺️ Architecture Highlights
* **Geospatial Engine:** 651,779 UK points of interest indexed locally from OpenStreetMap (Geofabrik) using `osmium-tool` for sub-15ms neighbourhood commute & rent analysis per UK postcode.
* **UK Tax Year 2026/27 Compliance:** Real-time take-home pay, Personal Allowance (£12,570), Income Tax, and Class 1 National Insurance calculations in £ GBP.
